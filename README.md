# ChurchCare Suite

A comprehensive church management and licensing platform.

## 📦 Project Components

- **[church-care-desktop-main](./church-care-desktop-main)**: Desktop application built with Tauri, React, and Rust for church operations and member management.
- **[licensing-microservice](./licensing-microservice)**: High-security licensing and hardware-locking microservice (Rust Axum server + Svelte 5 dashboard).

## 🚀 Getting Started

### 1. Desktop Application
```bash
cd church-care-desktop-main
npm install
npm run tauri dev
```

### 2. Licensing Microservice
Run `start_microservice.bat` in `licensing-microservice` or follow its [documentation](./licensing-microservice/README.md).
